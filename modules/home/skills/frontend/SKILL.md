# Frontend Design

Use the existing framework, component patterns, and tokens before introducing new abstractions. Inspect the current page and its nearby components first.

- Establish hierarchy, spacing, typography, color, and interaction states before writing markup.
- Prefer a deliberate visual concept over generic cards, gradients, excessive rounded corners, or dashboard-like filler.
- Make responsive behavior explicit for narrow, medium, and wide layouts; do not rely on accidental wrapping.
- Preserve keyboard access, visible focus, semantic structure, reduced-motion preferences, and sufficient contrast.
- Reuse existing assets and dependencies. Avoid adding a library for a small interaction that native HTML or existing code handles.
- Verify the result with the project's checks and, when available, a browser or screenshot pass at representative sizes.
